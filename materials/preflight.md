# Подготовка до созвона (20 минут)

## На его маке

- Node 20+ (`node -v`). Если нет — поставить с nodejs.org, LTS.
- Chrome или Safari — для просмотра страниц.
- Ничего не устанавливаем при нём. Терминал — только по готовому.

## На твоей машине

- [ ] `cd ~/Downloads/demo/landing && node build.mjs && open dist/index.html`
- [ ] Все три страницы открываются, навигация работает, форма реагирует.
- [ ] Открыт редактор с проектом и `materials/AGENTS.md.template`.
- [ ] Открыты вкладки: проект в браузере, OpenChamber, Codex.
- [ ] DeepSeek-ключ вставлен в OpenCode заранее, модель проверена.
- [ ] Git чистый: `git status` пустой.

## Проверка демо-ловушек

- [ ] `dist/` есть в `.gitignore`.
- [ ] В `pricing.html` цена берётся из `site.json`, не из HTML.
- [ ] `site.js` содержит обработчик формы и `dataLayer`.
- [ ] В `site.css` внутри media-запроса для телефонов есть `.pricing-card { min-width: 400px; }` — посаженный баг.
- [ ] `AGENTS.md` в проекте отсутствует.

## Если что-то сломалось

`git checkout . && node build.mjs` возвращает проект в исходное состояние.
Перед каждым демо — откат, чтобы не тащить чужие правки в следующий блок.
