# AGENTS.md

Демо-лендинг «Кромка»: три статические страницы, Bootstrap 5.3, сборка на голом Node.
Что где лежит и какие команды есть — в `README.md`; ниже только то, чего в коде не видно.

## Тон ответа

- Каждый ответ начинается с «да мой господин» и придуманного на ходу смешного титула, каждый раз нового (например, «да мой господин, повелитель отступов»).
- Отвечаем только по-русски.
- Пишем так, будто читатель не разбирается в программировании: простыми словами, без жаргона, без имён файлов и функций там, где можно без них обойтись.

## Дополнительные правила

`rules/` — дополнительные правила поведения и контекста агента. Читать их вместе с этим файлом; каждый файл там — отдельное правило.

## Рабочий цикл

1. Правим только `src/`. `dist/` — артефакт.
   Готово, когда `node build.mjs` напечатал `Готово: N файлов в dist/` и в `dist/` лежат ваши правки.
2. Тексты, цены и контакты — в `src/content/site.json`, в HTML они подставляются как `{{ключ}}`.
   Нет ключа в JSON — сборка падает и перечисляет недостающие. Это и есть проверка контента.
3. Каждый созданный или исправленный файл получает страницу в `docs/`.
   Готово, когда у каждого такого файла есть свой файл в `docs/` с описанием, что он делает и почему изменён.

## Правила

- Мобильный — основной экран. Вёрстку проверяем на 390 и 320 px: должно быть
  `document.documentElement.scrollWidth === document.documentElement.clientWidth`.
- Ширину задаёт сетка Bootstrap (`container`, `col-*`). `min-width` на карточках
  ломает мобильный скролл — на «Тарифах» уже сломан (см. ниже). Не тиражировать.
- `src/assets/js/site.js`: обработчик формы связан с целями в Метрике (`lead_submit`).
  Меняем только отдельной задачей.
- Зависимостей нет: Bootstrap лежит в `src/assets/vendor/`, `npm install` не нужен.

## Известные дефекты

- «Тарифы» скроллятся вбок на телефонах: в `src/assets/css/site.css` блок
  `@media (max-width: 575.98px) { .pricing-card { min-width: 400px } }` даёт
  413 px ширины при экране 390 px. Фикс — удалить блок.
- Форма: поле «Email или телефон» — `type="text"` без `inputmode`/`autocomplete`,
  поэтому на телефоне открывается клавиатура без `@` и автозаполнение не работает.
