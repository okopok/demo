# demo — учебный проект для вебинара по агентной разработке

- `landing/` — статический лендинг «Кромка»: три страницы, Bootstrap локально,
  сборка `node build.mjs` без npm и зависимостей.
- `materials/` — сценарий на 90 минут, промпты, шаблон `AGENTS.md`,
  шпаргалка и чеклист подготовки.

## Быстрый старт

```bash
cd landing
node build.mjs
open dist/index.html
```
